# Complaint and 8D Evidence Process

The register uses a generic D1-D8 evidence sequence:

1. D1 - identify the cross-functional team.
2. D2 - state the observable problem and scope.
3. D3 - record containment and immediate protection.
4. D4 - document supported root cause and escape point.
5. D5 - select corrective action and expected result.
6. D6 - implement and validate the corrective action.
7. D7 - record preventive or systemic improvement.
8. D8 - approve closure and recognize completion.

The loader rejects mismatches between recorded evidence and the complaint's current stage. A real process must additionally establish communication responsibilities, protected data handling, decision authority, evidence sufficiency and customer-specific timing.

At each review, confirm complaint severity, containment status, affected requirements, overdue actions, root-cause evidence, validation results and closure authority. Empty text is not accepted as completed evidence.
