# Standards and Claim Boundary

This project was informed by public descriptions of quality-management concepts, not by professional aerospace work or an organizational conformity assessment.

Public orientation sources:

- ISO's official [ISO 9001:2015 overview](https://www.iso.org/standard/62085.html).
- IAQG's official [9100 quality-management-systems overview](https://iaqg.org/standard/9100-quality-management-systems-requirements-for-aviation-space-and-defense-organizations/).
- ASQ's public [Eight Disciplines (8D) overview](https://asq.org/quality-resources/eight-disciplines-8d).

The repository does not reproduce standards text. Field names and workflows are generic demonstrations. Nothing here establishes compliance, certification, approved product assurance, audit competence or suitability for a mission-critical release.

An organization adopting a similar pattern would still need to identify licensed requirements, customer and statutory obligations, process owners, approval authorities, configuration controls, record-retention rules and independent assurance activities.
